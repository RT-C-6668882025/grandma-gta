## 1.13：动作修复与触控

修复了连续切换动作时的残留姿势：旧动作在淡出期间仍参与混合，接新动作后失去管理；现在替换动作时会停止旧动作。另将脚步声改为跟随实际地面位移，撞墙、飞行时不会凭移动指令持续响脚步。

操作采用移动射击游戏常见的双拇指分区：左下浮动摇杆与前推冲刺，右侧滑动视角、长按攻击、情境互动和投掷。攻击按钮本身也可拖动视角；按键大小与灵敏度可保存。键鼠以 WASD、左右键、E 和 Shift 为主，旧快捷键保留。

已用真实阿嬤模型验证旧动画退出播放；浏览器验证了多指独立释放、暂停清理、手机 / 平板 / 竖屏布局和 E 键上下车。尚未等同于《和平精英》的完整自定义键位系统，真机手感继续迭代。

## 1.12：主角动作优化第一轮

对比原项目的 `actor.js` 与 `entities.js`，沿用阿嬤的现有骨骼和动作资源，先调整地面移动与动画之间的连接。

- 起步逐渐加速，松手更快收步；大角度掉头先减速再前进。
- 步频根据碰撞后的实际位移计算，撞墙停住时回到待机。
- 主角走路、摇摆步和跑步使用按混合权重计算的参考速度，减少步频与位移不匹配。
- 战斗命中、骑乘、飞行与飞扑继续使用原有专门逻辑；「日志」名称不变。

这轮没有更换模型，也没有新增动作捕捉、专用起停 / 原地转身动画或地面脚部 IK，不能等同于《赛博朋克》的动作质量。建议先关闭「加速」体验普通步态；高倍速能力仍保留，动画播放速率上限为 4 倍，极端速度仍可能滑步。后续重点是补齐转身与起停动作，再处理脚底贴地和手部交互。

## 1.11：先走进一个经济街区

点击顶部 **「街区」**，选择店铺。经营卡显示资金、库存、到岗员工、通勤人数、前来消费的人数和工资；可直接注资、调整每人工资、开停业、导航或查看该店日志。

在街上，店铺标牌显示营业、缺货或停业，门前货箱数量跟随库存。标牌可点击，附近同时最多显示三个，减少遮挡。

试验街区的步行员工需要抵达店口，才领取当轮工资并参与生产；顾客沿道路到店后才付款、减少库存和完成消费。资金不足、未到岗、停业、缺货分别产生不同结果，受伤或战斗优先。

**「日志」仍叫日志。** 店铺操作带有决策编号，相关收支和事件保留关联与地点，可点击「前往现场」。原有全镇轮次对比仍属于同期变化，不代表唯一因果。

本次只把选定街区接入到店循环，其余产业继续采用原规则。还没有扩展为全地图逐人到岗或完整交通物流仿真。

## 先这样玩

1. 点击顶部的**经济条**，进入小镇发展控制台。
2. 查看产业列表：企业缺钱就注资或定向增发；人口不足可点击「新增 32 名居民」。新增居民不会自动补足企业工资。
3. 修改汇率，选择固定或市场浮动；点击「应用汇率」。
4. 推进一轮，或调整模拟速度，查看就业、GDP 和产出变化。
5. 打开顶部的**日志**，筛选「决策反馈」，查看操作后的下一轮变化。
6. 在产业、居民或资产旁点击「导航」或「瞬移」，到场景里查看对应位置。

## 货币、产业与发展

### 只有两种货币

| 货币 | 初始设置 | 用途 |
| --- | --- | --- |
| NT$ | 全镇总量 15,000；玩家经济钱包 1,000 | 工资、消费、采购、服务及兑换 |
| GOD | 总量 2,100；玩家持有 2,000，矿池 100 | 可开启产业结算、兑换、订单交易和挖矿 |

GOD 是原 BETA 的新名称，沿用已有资产。它是本地游戏内货币，没有连接真实区块链或资金。

**增发与注资分开：**

- **定向增发**：选择数量、币种和目标，增加该货币总供应。目标可为玩家、公库、指定居民、产业或资产专项账户；列表中的「增发至此」可直接选中对象。
- **注资**：把玩家已有资金转给产业，不增加总供应。「平均注资全镇」输入的是总预算。
- **资产专项账户**：独立显示 NT$ / GOD 余额；载具账户优先承担维护费，动物账户可支付饲料费，其他资产账户保留专项资金。
- **矿池**：可补充 GOD 矿池，由符合条件的居民挖矿领取；矿池耗尽后不再发放。

### 汇率与交易

初始参考汇率为 **1 GOD = NT$10**。可选择市场成交价，或手动固定为 **1～100000** 的整数。

固定模式下，市场成交不会覆盖结算汇率。工资、商品和兑换使用结算汇率，市场成交价另行显示。GOD 按整枚结算，换算时向上取整。

兑换受钱包和公库储备约束。余额不足会拒绝操作，不凭空补足资金；修改汇率本身也不增发货币。GOD 订单市场支持买卖、部分成交和撤单，成交价格由订单撮合产生。

### 产业怎么运转

居民获得工资后消费，产业通过销售回收资金，再采购、生产和扩建。农业、食品、零售、维修、医疗、休闲、住宅、交通与公共服务按各自的简化规则参与经济。

- 有资金和岗位的企业招聘；缺资金、等待招聘、缺原料和停业分别显示。
- 场地支持注资、开业 / 停业和结算币种切换。
- 车辆可编入运输队，设备影响附近产业产能，动物消耗饲料。
- 玩家商店买卖受库存和账户余额约束；任务奖励由公库支付，不足部分记录为待付奖励。
- 场景经济使用真实账户余额；「无限钱」能力不会替经济账户补款。

### GDP 与模拟时间

**游戏 GDP 使用最终消费口径**，剔除批发、换汇和资产转手，便于观察小镇消费活动；它不是完整的国民经济核算模型。

默认每 15 秒推进一轮，可调整为 1～16 倍速度。经济控制台和日志打开时继续模拟；其他菜单、部分剧情状态和切后台会暂停，不补算离线时间。

## 日志：看见决策后的变化

点击顶部「日志」或按 **L**。支持按类型筛选、关键词搜索和分页查看。

日志记录汇率调整、增发、注资、生产开关等操作，并关联下一轮的就业、GDP、产出变化；同时记录两币收支、产业状态、入职、交易、挖矿、任务与导航等事件。

反馈展示的是**操作后的同期变化**，多项决策和其他事件可能共同影响结果。最近 **10,000 条**随存档保留；「导出日志」可查看原始文本并全选复制。

## 操作方式

### 触屏

推荐横屏。左下区域按下即可生成摇杆，支持正前、左前、右前等八方向；轻推慢走、前推超出外圈冲刺，回收后恢复普通移动。右侧空白处拖动视角，攻击按钮也能边按边拖，长按连续攻击。

- **右侧主按钮**：攻击、互动 / 上下车、投掷、补药。上车后自动显示下车、刹车和任务投掷。
- **顶部菜单 → 操作设置**：调整并保存视角灵敏度（默认 35%）和按键大小（80%–120%）；次要动作集中在这里。
- **多指操作**：移动、转视角、动作分别持有自己的手指；松手、切后台或打开面板会正确释放。
- **外接键鼠**：可关闭触控操作区，需要时再从菜单打开。

### 键鼠

日常只需以下操作：

| 操作 | 按键 |
| --- | --- |
| 移动 / 奔跑 | WASD / Shift |
| 攻击 | 左键，长按连续攻击 |
| 投掷 / 转动视角 | 右键轻点投掷；右键拖动转视角；默认也支持鼠标移动转视角 |
| 情境互动 / 上下车 | E；附近有互动时优先互动，F 仍可直接上下车 |
| 背包 / 菜单 | Tab / Esc |
| 驾驶 | WASD；空格刹车 / 喇叭 |

鼠标模式可在顶部菜单切换；锁定视角模式需要点击画面获取鼠标。轻点右键与拖动分开识别，拖动不会同时触发投掷。屏幕中心显示准星。

可选旧快捷键仍可用：C 切换镜头、Z 回正、滚轮调距离、M 地图、T 手机、O 能力、V 飞行、PageUp / PageDown 升降、J 攻击、G 投掷、N 经济、L 日志、R 电台、Q 痞步、H 补药、X 抽烟、B 槟榔；步行时空格骂人。

地图支持鼠标滚轮或双指缩放、拖动平移。点击地点建立路线；瞬移落在目标附近道路，最后一段可继续跟随引导步行。路线不包含实时交通绕行。

## 存档与实现范围

自动存档保存在当前设备，也可在经济面板手动存档。货币、产业、汇率、人口设置和日志随存档保留；重新开始会重置游戏。

这是单机、按行业规则运行的经济实验。尚未实现多人联机、完整军政与暴动系统、自动出生或游戏内 3D 模型导入编辑器。当前能力以本页和对应版本发布说明为准，旧版本说明见 [Releases](https://github.com/RT-C-6668882025/grandma-gta/releases)。

## 本地运行与开发

网页无需安装 npm 依赖：

```bash
git clone https://github.com/RT-C-6668882025/grandma-gta.git
cd grandma-gta
python3 tools/serve.py
```

打开 `http://localhost:8965`，修改代码后刷新。添加 `?nostory` 可自由游玩，`?autostart` 可跳过标题画面。

| 模块 | 文件 |
| --- | --- |
| 试验街区规则与场景交互 | `src/district.js`、`src/district-scene.js` |
| 经济控制台 | `src/economy-dashboard.js` |
| 行业模拟与场景绑定 | `src/world-economy.js`、`src/world-bindings.js` |
| 账户、增发与事件记录 | `src/economy-ledger.js` |
| 独立日志界面 | `src/event-journal.js` |
| 汇率与双币结算 | `src/town-currency.js` |
| GOD 市场与挖矿 | `src/crypto-market.js` |
| 触控与界面布局 | `src/touch.js`、`src/touch-motion.js`、`src/ui.css` |
| 地图与导航 | `src/map-panel.js`、`src/map-navigation.js`、`src/main.js` |
| 居民、角色与车辆 | `src/residents.js`、`src/resident-scene.js`、`src/entities.js`、`src/vehicles.js` |
| 镜头与能力 | `src/camera.js`、`src/camera-modes.js`、`src/mods.js` |
| 任务 | `src/story.js`、`src/chapter2.js` |
| Android 外壳与构建 | `android/`、`.github/workflows/android-apk.yml` |

运行测试：

```bash
node --test tests/*.test.mjs
```

Android 构建需要 Java 17、Android SDK Platform 35 和 Build Tools 35.0.0：

```bash
bash android/build.sh
```

输出为 `android/build/grandma-gta-phone-tablet.apk`。GitHub Actions 会在游戏及安卓构建相关文件变更后构建 APK。更多说明见 [Android 构建说明](android/README.md)。网页模型压缩可运行 `python3 tools/pack-models.py`。
