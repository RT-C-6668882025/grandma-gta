## 1.9：全场景经济接入

入口：**N / 能力 → 小镇经济**，也可直接点击顶部实时经济条。

- 初始实测 **509 个场地、64 名 NPC、223 个功能资产**。场地包含商店、住宅、农田、公共设施及合作社账户；资产包含载具、动物和设备。这是场景实例登记数量，不是独立 3D 模型文件数量。
- 场地有独立账户、库存、员工、营业状态和等级；按行业规则模拟工资、采购、消费、租金、税收及扩建。NPC 映射到现有场景角色，不重复生成。载具可购入并调度物流，动物消耗饲料，设备提升附近产业产能。
- 汇率可选市场成交价或手动固定整数 **1～100000**。结算汇率和市场价格分开显示，双币付款统一使用结算汇率；设置随存档保存。
- 经济面板打开时继续推进，支持 **1～16 倍**速度和手动轮次，实时显示就业、产销、下一轮倒计时、历史趋势与发展阻碍。切到后台仍暂停模拟。
- 玩家商店买卖受真实库存和账户余额约束；任务奖励由公库支付，不足部分等待后续结清。全镇注资输入的是总预算，会分摊到营业场地。
- 旧存档保留钱包。首次接入将原有生产与零售运营资金分配给部分产业，未获资金的产业需要注资；不会隐式增发货币。

这些是按行业运行的简化经济行为，并非每种模型都有独立复杂 AI。模型文件的导入/替换编辑器不在本次改动范围内。

## 1.8：汇率、兑换与产业打通

入口：**N / 能力 → 小镇经济 → 启用我的币 → 我的货币 · 现有产业**。

- 统一汇率读取市场最近成交价，初始 **1 BETA = NT$10**。居民交易在产业模式继续运行；有成交才改变行情，无成交保持原价。
- 支持 NT$ 买 BETA、BETA 换 NT$。公库作为有限兑换池，初始 NT$2,000、0 BETA；可先卖币给公库补充币库存。钱包或池内资金不足时拒绝兑换，两条资产转账一起完成，不增发资产。
- 六处产业分别持有 NT$ 与 BETA，可选择任一种注资和结算。工资、商品、批发、服务付款与送货按同一汇率换算；付款币种不足时尝试用另一钱包兑换，受公库储备限制。
- 商品保留库存与增发因素形成的 NT$ 原价，再换算 BETA；工资基准 NT$28、运费 NT$40。整枚 BETA 向上取整，界面显示双币报价，暂不支持小数币。
- 双币余额、产业结算偏好、账本、市场行情与兑换记录随存档保存。1.7 产业新增 NT$ 钱包初始为零，已有持币与普通货币保留。

## 居民与产业入门

入口：**N / 能力 → 小镇经济 → 启用我的币**。旧存档保留原钱包与资产，不会自动兑换或重新分币。

1. 在「我的货币 · 现有产业」为菜市场和柑仔店注资，例如各 100 BETA；资金从你的钱包转出。
2. 推进一轮，或关闭面板继续游玩。产业向到岗居民支付每轮 2 BETA 工资，居民用币购买商品。
3. 可给其余产业注资、停业 / 开业，查看 BETA 收支，或点击产业「导航」。你仍独占增发权，可补充个人钱包或矿池。

- 居民拥有保存后不变的永久 ID（如 `R000001`）；迁出后新居民不会复用旧 ID。绑定现有 3D 路人，工作地点随产业分配，保留战斗和受伤行为优先级。
- 菜市场与柑仔店接入生产、库存、批发与商品消费；五金行、诊所、回收场、槟榔摊先接入工资与定期服务付款。后四处的具体服务效果仍沿用原玩法。
- 麵包、汽水、寶力大補与送货按产业选择的币种付款，BETA 价格由统一汇率换算。其他商品和任务仍沿用原钱包，尚未实现万物结算。
- 此模式保留居民交易，BETA 同时用于支付；挖矿每 3 轮获得 1 枚，受矿池、到岗与生产开关限制，不额外扣 NT$ 电费。原 NT$ 与订单市场实验可保留切回。
- 地图点击地点、搜索结果或空白位置立即建立导航；拖动只平移地图。道路路线、距离和到达提示保留。

当前没有独立军政系统、居民选举、警局预算或自动出生机制。这一版先打通居民身份、产业与币的实际用途。

## 小镇货币系统（实验版）

按 **N**、能力菜单里的「小镇经济」，或触屏「更多 → 小镇经济」打开面板。

- 工资、消费、批发、分红、运费、增发与交易托管进入收支账本，保留最近 120 笔与累计账户收支。
- 初始货币总量 NT$15,000，阿嬤独立的小镇钱包 NT$1,000。居民工资、消费、商店补货和送货运费均转账，只有手动增发创造货币。
- 默认 24 名居民，每 15 秒推进一轮；菜单、暂停及切后台时不补算时间。最多 24 名居民绑定场景路人，工作 / 挖矿需抵达目标，战斗与受伤优先；其余居民在后台模拟。
- 麵包、汽水、寶力大補接入真实库存和动态价格，购买使用小镇钱包；其他商品、原任务收入与无限钱保持原玩法。
- 到菜市场领取 10 份麵包，送到柑仔店，打开面板交货赚 NT$40；需商店有足够资金。面板可导航。
- 可停止 / 恢复生产、手动推进一轮、增发 NT$1,000，观察库存、价格和居民未满足需求。增发对价格的影响是简化规则。
- 自动存档包含经济状态；旧存档自动补充初始经济数据，重新开始会重置经济。

## Beta 加密货币市场

入口：**能力 → 小镇经济 → 进入 Beta**。默认关闭；只做本地游戏内资产模拟，未接入真实区块链、钱包或资金。

- **初始供应 2,100 BETA**：玩家默认持有 2,000，矿池预留 100，居民初始持币为零。居民每轮挖矿支付 NT$2 电费，累计 3 轮矿工工作获得 1 枚；矿池耗尽则停止。关闭 Beta 暂停挖矿，重新开启不重新分币。
- **发币权属于玩家**：发行者控制台可增发给自己，或投入居民矿池。每笔记录数量与去向，增发只增加币的总供应，不凭空增加普通货币。
- 买单冻结普通货币，卖单冻结持币；价格优先、同价时间优先，成交使用较早订单的价格，可部分成交。撤单返还未成交部分与资金，成交价格改善时退回差额。
- 无对手时订单保留；初始参考价为 NT$10，之后由真实模拟成交更新，不用随机数生成价格。每账户最多 10 笔未成交单。
- 居民保留生活费，资金不足 / 需求未满足时卖币，资金充裕时买币；挂单及交易不会凭空创造货币或币。
- 现金超过 NT$600 且可用持币估值超过 NT$2,000 的居民暂停工作；现金超过 NT$700 增加消费，财富变化传导至生产与商品库存。居民策略与阈值是简化实验规则。
- 关闭 Beta 撤销所有订单并退款，保留持币、成交记录及已有经济后果。旧经济存档自动迁移，订单、托管和持币随游戏保存。
- 模拟成交历史保留最近 60 笔。此版本不包含真实链上转账或多人共享市场。

## 居民与地图（1.6）

- 「小镇经济 → 居民管理」查看姓名、年龄、现金、持币、累计挖矿和当前工作，可切换 12 / 24 / 48 / 96 人。场景可见居民最多 24 人，复用原有路人，避免手机同时渲染大量新角色。
- 新居民由公库支付最多 NT$100 安置费，初始持币为零；减少人口时，先退回未成交订单，居民现金回公库，持币回矿池，保持资产总量。
- 场景居民在生产点、菜市场旁算力站和住处间移动。远处角色采用简化移动，不每帧运行完整角色渲染；后台居民仅模拟经济。
- 地图按 **M**，触屏点「地图」：可搜索、筛选商店 / 居民 / 挖矿送货 / 任务，鼠标滚轮或双指缩放、拖动平移、点选标记或任意位置导航。
- 导航沿现有道路生成参考路线，同步显示在小地图，并显示距离和到达提示。最后一段可能需要步行穿过院落；未模拟实时交通绕行。地图范围仍为原小镇。
- **旧版 Beta 存档迁移**：旧挂单先退款，普通货币保留；旧持币按「玩家 2,000 / 矿池 100」重新分配。此迁移仅执行一次；后续增发、交易、挖矿均随存档保留。

## 怎么玩

### 触屏

推荐横屏打开，网页也适配竖屏：左下模拟摇杆移动，轻推慢走、推满全速，支持斜向。另一根手指拖动画面转视角，还可同时按右下的攻击、互动、上下车、奔跑等按钮。松手、切后台或暂停会释放输入，避免卡住。

顶部可打开背包、手机、地图与暂停；「视角」切换三种镜头，「能力」切换魔改能力。「更多」展开飞行、上升、下降、补药、电台与视角回正等操作；上车后动作按钮会显示下车和刹车 / 喇叭。

使用外接键鼠时，可点「触控：关」隐藏触屏操作区。

当前版本已有 107 项自动测试通过，覆盖输入、触控、货币与持币守恒、挖矿、人口调整、存档迁移和道路导航；自动测试不替代真机体验验证。

运行测试：

```bash
node --test tests/*.test.mjs
```

网页模型打包：

```bash
python3 tools/pack-models.py
```

Android 构建需要 Java 17、Android SDK Platform 35 和 Build Tools 35.0.0：

```bash
bash android/build.sh
```

输出：`android/build/grandma-gta-phone-tablet.apk`。GitHub Actions 也会为游戏与安卓代码变更构建 APK；更多说明见 [Android 构建说明](android/README.md)。
