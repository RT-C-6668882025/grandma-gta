# 战斗核心接入契约

状态：src/combat-core.js 已实现；src/combat-demo.js 已接入可选的「战斗试验」。默认漫游保持旧操作，进入试验启用新规则；这是手感原型，不是完整战斗系统。

## 当前可玩据点

「源核据点」进入独立院区，目标为取得终端内芯片并返回入口。三名守卫根据视线、朝向、声音和警报感知玩家；失去目标后搜索最后已知位置，掩体与侧翼角色使用受障碍约束的网格寻路。射击前有可见前摇，射击落点使用前摇时记录的位置，闪避不提供无敌。

枪械左键/攻击按钮射击、右键瞄准；近战短按释放轻击、长按 .32 秒产生一次重击、右键格挡。正面格挡扣体力，开始 .22 秒内为完美格挡，背后攻击不能格挡。R 换弹、Q 扫描开关、Ctrl 潜行、空格闪避、3 切换枪械/近战（1/2/K 快捷键兼容）。E 根据上下文执行：潜行背后处置、近距离取芯片，或扫描模式确认破解。

破解中继器开放终端远程权限并干扰守卫武器八秒；摄像头停用十八秒；破解守卫造成伤害与八秒干扰。施法逐帧检查目标、距离、遮挡和扫描状态，受伤会打断；已支付 RAM 不退还。追踪值过高触发警报。潜行降低视线发现速度和脚步噪声，不能自动免于摄像头发现。

首次完成最多 NT$100 从银行转账，非新增货币；每次完成经验 +100，每 100 经验一个技能点。精准增幅、算力优化、运动义体为真实伤害/资源规则升级，不可重复购买。开始、处置、警报、取芯片、完成路线及升级写入原「日志」。终端、中继器、撤离点接入既有地图标记。

结束恢复原位置、镜头、生命、体力及步行模式；临时院区地面偏移、地图标记与资源清除。禁止保存院区位置，退出后保存成长和日志。剧情暂停，经济继续；战斗体力由核心唯一管理。试验弹药独立于背包，不保存进行中的遭遇。

手机与平板提供八个战斗按钮：攻击、瞄准/格挡、操作/处置、闪避、换弹、扫描、潜行、切换。移动与看向使用独立指针，沿用触控设置。浏览器验证 844×390、1280×800 的按钮矩形无重叠或越界；实机性能与手感仍需验证。

## 资产与范围

枪械、手部与机器人由代码构建，含后坐力、装填位移、移动腿部、受击和倒地反馈，未实现正式持枪骨骼动画。命中为近似球体及高度判定头部增伤，不是骨骼精确命中；原音效复用。独立据点之外保持原漫游战斗，没有全城敌人替换、多武器背包、智能弹道或穿透。

## 模块协议

`createCombatState()` 创建战斗状态。`stepCombat(state, intents, context, dt)` 返回 `{state, events}`，不修改输入对象。所有时间以秒计。一次只发起一种动作，优先级：死亡/禁用 → 受控 → 换武器 → 闪避 → 正在进行的动作 → 破解 → 换弹 → 格挡 → 攻击。

intents：fire/reload/melee/heavy/dodge/hack 是动作请求；aim/scan/block 是当前按住的状态；weapon 为 gun 或 melee。输入层必须处理长按、边沿、触摸取消和菜单关闭后重新按下，不能用上一帧缓存制造幽灵攻击。扫描本轮为扫描开关的按住状态，UI 可将 Q 切换状态转换为该布尔值。

context：dead/mounted/blocked/reset/stunned，由世界提供真实状态。hackTarget 为 `{id, valid}`，valid 必须每步根据实际存活、距离、可见性及设备权限重新计算。invalid 或目标变化取消施法，已支付 RAM 不退还；这是本轮确定的失败成本。菜单、驾驶、死亡、重置清除动作与瞄准/扫描，不完成旧换弹或破解。reset 用于载入、复活切换时的明确清理。

dt 非有限或负数按零；单步最多 .1 秒。调用方应使用固定小步模拟，不用长 dt 补偿后台时间。此模块不是离线进度结算器。恢复资源只在可运行、未受控时进行；动作数值为首轮手感参数，尚未经过实机平衡。

## 世界适配器必须完成的工作

| 输出事件 | 世界接入要求 |
|---|---|
| shot | 从镜头方向产生射击请求；检查枪口遮挡与最近交点；应用一次实际伤害，生成音效、后坐力、命中特效 |
| meleeStarted | 播放相应动作；显示动作与核心前摇时机同步，不再调用旧 resolveHit 回调造成二次伤害 |
| meleeContact | 在此刻检测距离、朝向和遮挡，调用一次伤害接口；事件本身不代表已打中 |
| dodge | 按当前输入方向尝试位移并通过真实碰撞约束；不默认无敌或穿墙 |
| reloadStarted / reloaded | 播放动作、更新 HUD；弹药只由核心在完成时转移，动画不能另加弹药 |
| hackStarted / hackApply | 播放扫描反馈；完成事件再验证目标，应用有期限的设备效果 |
| hackCancelled | 清除进度与目标提示；不重复扣资源 |
| weaponChanged | 同步装备、第一人称模型和按钮语义 |
| empty | 无弹提示；不开枪、不应用伤害 |

事件 ID 是该状态实例递增序号，用于适配器去重；不要因每帧 render 再执行事件。`guardDamage` 提供正面减伤、完美格挡与体力扣除；世界适配器判断攻击方向。敌人 AI 位于 `combat-ai.js`，任务与升级位于 `combat-mission.js`，触控与鼠标意图位于 `combat-intents.js`。核心本身不负责世界碰撞或动画资产。

当前 stamina 与 ram 属于新核心资源。实际接入 Player 时必须统一旧 stamina 的唯一所有者，不能新旧系统同时恢复或扣除。核心弹药目前只支持一把示范枪；多武器弹药与存档 schema 等示范据点验证后扩展。
