# 人物与场景资源约定

人物、武器和道具沿用原作者的资源方式。没有合适资源时延期，不用临时拼装人物、手臂、枪械、机器人或装饰物充当正式模型。

## 现有流程

- 人物：Tripo 生成的 GLB，使用原骨骼与动作；`loadActors` 加载模板，`Actor` 通过 SkeletonUtils 克隆，复用动作混合、受击与倒地。不得用几何人形替代。
- 道具：原 GLB 经 `loadPropModels` 归一化；`placeInstanced` 批量放置、计算碰撞并接入原设施登记。缺失模型跳过该装饰，不另建低质替代物。
- 建筑：原 `town.js` 的 `shophouse` 与 Kit 合并生成。新区通过回调复用该生成器，不再单独维护一套只有方块外壳的建筑。
- 装备：沿用 gear 的 GLB 与骨骼挂点。正式枪械、持枪手臂和枪械动作缺少资源，暂不显示占位外观；射击规则与准星保留。
- 新资源遵循原作者 Tripo → 纹理 → 骨骼/动画 → GLB → 检查/精简 → 加载/缓存流程。未具备可调用生成能力时，继续交互、算法和任务，不宣称资产已生成。

## 生命周期与兼容

Actor 克隆的几何和贴图来自共享模板。销毁遭遇时先停止动作、移除克隆并释放其独立材质，再销毁临时场景几何；不能遍历角色并释放共享几何或贴图。

复用新区建筑时关闭重复产业登记，既有地块 ID 与账户继续使用；新增原 GLB 设施沿用已有登记规则，不凭空发行货币。导航中央通道保留，加入装饰后重新检查真实碰撞。

## 当前交付

守卫复用 `thug2.glb` 与 Actor；新区复用原建筑生成器；中心使用已有办公桌、货架、收音机、小吃车、凳子和石凳。撤下临时枪械、手臂、刀、机器人、喷泉及展示环。正式枪械、喷泉与专属科技设备资源延期。
