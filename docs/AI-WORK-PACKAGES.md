# 小镇改造：AI 施工任务包

状态：设计与交接规范，尚未实现。基线：1.16-districts，代码树 a4083710d5bd0c5d37bb341cbe9d3c87710e53e0。

## 共同设计

番薯寮是全球最发达、发展最快的城市。阿嬤回来时掌握处于科技最上游的「源核」芯片核心技术。她能影响技术授权和货币，制造、应用和社会协作仍需要居民与组织。

三个街区都是完整、领先全球的社会生态，不能按低中高科技等级或制造/服务/研发部门划分：

| ID | 名字与面积 | 审美 | 社会优势 | 主要断点 |
|---|---|---|---|---|
| dongbu | 东埠区 25% | 密集街巷、改装设施、廉价霓虹 | 人口密度、竞争、频繁的黑科技发明 | 普遍变现能力弱，创新收益容易外流 |
| yuting | 榆庭区 45% | 法意德石材、庭院、拱廊、广场 | 生活幸福、制度可靠、专业积累与信任 | 改变现状的动力较弱 |
| chengwan | 澄湾区 30% | 硅谷玻璃园区、绿地、开放空间 | 资本、资源、前沿研究与规模化 | 对普通需求理解不足，技术难以下沉 |

街区倾向允许个体例外。全城发展不能靠凭空增发资产实现。店的位置固定，控制人可变；居民通过实际收入积累 NT$ 和 GOD。两次点击内完成主要干预，后果可见，并进入「日志」。

## 谁负责什么

主设计者负责审美样例、经济与行为算法、战斗状态机、触控手感、任务结构和最终整合。施工 AI 负责下列明确范围内的数据、兼容、批量资源登记和接线。阶段门标为“等待”的任务不得提前自行设计核心规则。

各任务用独立分支，提交补丁，不直接合并主分支或发版。并行只适用于文件互不重叠的任务。不要改 Android 包名、签名、证书、CI 密钥、发布标签；不要重命名「日志」；不要全仓格式化。

## A：居民属性数据层（现在可做）

允许文件：新增 src/resident-profile.js、tests/resident-profile.test.mjs。只读 src/residents.js、src/town-agents.js、src/city-regions.js。先不接入工资、招聘、迁移或交易算法。

新增接口：

```js
createResidentProfile(uid, regionId) // 返回新对象
normalizeResidentProfile(value, uid, regionId) // 返回规范化副本
```

结果格式：`{version:1, originRegion, traits:{invention, commercialization, changeDrive, everydayInsight, ambition, riskTolerance, reputation}}`。七项均为 0..100 的有限整数；originRegion 只接受三个既有 ID；未知区域回退 yuting。version 不支持时按初始规则重建此对象。

初始均值：东埠前三项与 everydayInsight 为 85/30/80/70；榆庭 65/65/30/80；澄湾 90/85/80/30。其余 ambition/riskTolerance/reputation 分别为东埠 75/75/45、榆庭 45/35/70、澄湾 85/85/55。这些是首轮可调整的游戏参数，不是现实国家统计。使用 uid 和属性名的稳定字符串哈希，每项加 -15..15 的个体偏移，再限制到范围。不使用 Math.random，不依赖数组下标。

normalize 保留有效字段；缺项补默认，有限数字四舍五入并限制范围；NaN/Infinity/字符串等回退默认。不修改输入或居民身份，不创建余额、资产、持币或关系。

验收：同 uid 与区域多次结果一致；不同 uid 有差异；跨区分布有重叠且均值符合倾向；非法输入安全；输入对象不变；输出 JSON 往返一致。交付新模块与测试、函数用法、结果摘要。

## B：街区社会配置（现在可做，可与 A 并行）

允许文件：新增 src/region-society.js、tests/region-society.test.mjs。只读 src/city-regions.js。不得修改地图边界、既有建筑或居民数据。

导出 `REGION_SOCIETY`，以三个既有 ID 为键；每项包含 `name`、`strengths`（三条短文本）、`bottleneck`、`visualCues`（三条）、`occupations`（六条）。内容遵循共同设计。职业三边都要含技术、经营、公共生活角色；不得把普通居民全部变成战斗敌人。

导出 `societyFor(regionId)`；未知 ID 返回榆庭配置。返回配置只读，调用者不能意外修改共享数组。不要附加未经确定的收入、产量、幸福度或战斗倍率。

验收：ID/名字与 CITY_REGIONS 完全对应；各区优势、断点与视觉线索不同；区域回退有效；无 DOM、Three.js、经济模块依赖。交付配置、测试及用法。
